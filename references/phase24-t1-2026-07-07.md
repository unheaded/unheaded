## Method

Same proven loop as Phase 2.3, per file: read vendored source (patch audit) →
u-file in `adapters/` (SPDX GPL-3.0-or-later, bodies kept verbatim) → one OBJS
line swap in `Makefile.mbc` → kbuild → FILE-symbol proof (`objdump -t | grep
'df \*ABS\*'`) → smoke (`echo hello` TTY+stats byte-diff vs golden) → full
16-gate harness → commit. Verbatim bodies are load-bearing: GCC -O2 then emits
identical code and the translation count is a free semantic tripwire — it held
at **7,552 RV32I → 11,764 MBC** for every build this sprint. Verifier budgets
exact every harness run: ascend 900,031 (90.0%), Doom 737,087. Zero eBPF
changes.

## Footguns confirmed / learned

- Goldens in /tmp die on every reboot (third strike). Recapture-from-HEAD is
  now the standard remedy once a phase's equivalence proof is committed — the
  A7 stock-revert dance is only for mid-phase recapture.
- The persistent-shell cwd bites: a `cd` in one Bash call leaks into the next;
  a kbuild launched from repo root silently no-ops into a grep-eaten make
  error. Always `cd $UP &&` explicitly in build commands.
- kbuild rewrites `target/xv6-mbc.mbc` in place — never build while a boot or
  golden capture is in flight (torn read).
