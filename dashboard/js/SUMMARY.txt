PURPOSE: Monad packet inspection, circuit breaker tracking, chaos injection

KEY FEATURES:
✓ Monad Decode Panel (12 DOM elements)
  - Flow action: FORWARD/TRACE/SAMPLE/MIRROR/DROP with color indicator
  - Hop count: with accent styling for high values (>5)
  - Flags: decoded from bitfield (TRACED, SAMPLED, MIRROR, CHAOS, CUSTOM)
  - Circuit state: CLOSED/OPEN/HALF with state-specific coloring
  - CRC checksum: with ✓/✗ validity indicator
  - Service IDs: source and destination (derived from IP last octet % 16)
  - Registers: [r0, r1, r2, r3] values
  - Scratch registers: r0 and r1 with assignment notation
  - Flow label: hex representation (fl=0x####)
  - Hex dump: 20-byte fake representation for visualization

✓ Monad Synthesis from PacketFlow
  - Extracts protocol, hop count, status code
  - Maps HTTP status to circuit states (503→OPEN, 429→HALF, 200→CLOSED)
  - Derives service IDs from IP addresses
  - Generates fake register and scratch values
  - Creates synthetic CRC for demo purposes

✓ Circuit Breaker Matrix
  - Tracks up to 20 service-to-service pairs
  - Format: "svcA→svcB" with state and age
  - Updates based on HTTP status codes
  - Renders dynamic list with real-time aging
  - Maintains count of OPEN circuits with danger coloring

✓ Chaos Injection Control
  - Input validation: hex flow label regex (/^[0-9a-fA-F]+$/)
  - Mode selection: bit_flip, delay, duplicate, truncate, marker
  - Conditional delay parameter input (shown only for delay mode)
  - POST /api/v1/chaos with payload: { flow_label, mode, param }
  - DELETE /api/v1/chaos/stop to terminate
  - Timestamped log (max 10 entries, auto-scrolling)
  - Status chip indicator for active/inactive state
  - Error logging to chaos panel (no exceptions thrown)
