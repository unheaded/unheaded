# Before this file existed there was no Python dependency manifest anywhere in
# the repo, which meant `syft dir:.` — the SBOM step in ci.yml — found ZERO
# packages here, so grype had nothing to scan. A CVE in flask, requests or
# psycopg2 was caught by no gate. That is what this file is for first;
# reproducible installs are the secondary benefit.
#
# DIRECT imports only, not a freeze. Transitive dependencies are resolved by pip
# and reported by syft from the installed environment. Versions are the ones
# running in ~/.venv/zhen today, each confirmed importable — not aspirational.
#
# torch is deliberately unpinned to a build: the ROCm wheels come from a
# different index (see ~/.venv/zhen-rocm and CLAUDE.md's ROCm notes), and
# pinning the CPU build here would fight the GPU setup. Install the variant that
# matches the accelerator, then the version below.
