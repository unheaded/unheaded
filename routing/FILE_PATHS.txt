frr.conf
────────
Purpose: Main FRR routing daemon configuration (host-a)
Content:
  • Interface definitions (loopback, WAN, LAN bridge, WireGuard)
  • IS-IS underlay routing (L2-only, segment routing enabled)
  • BGP EVPN overlay (iBGP to host-b, VNI 10001/10002/10100)
  • BFD fast-failover (300ms detection)
  • Route-maps and prefix lists (HbH-transparent)
  • VXLAN VTEP management via zebra
Syntax: FRR configuration language
Deploy to: /etc/frr/frr.conf
Test with: vtysh


daemons
───────
Purpose: FRR daemon startup control (host-a)
Content:
  • Enabled daemons: zebra, bgpd, isisd, bfdd, staticd, mgmtd
  • Disabled daemons: ospf, rip, pimd, ldpd, nhrpd, etc.
Format: Key=yes/no lines
Deploy to: /etc/frr/daemons
Required by: systemd frr.service


vtysh.conf

  • Enable integrated-vtysh-config (merge all daemon configs)
  • Allow root passwordless access to CLI
Format: Simple config directives
Deploy to: /etc/frr/vtysh.conf
Usage: vtysh (interactive shell)


setup-vtep.sh
──────────────
Purpose: Pre-boot VXLAN VTEP interface creation (host-a)
Content:
  • Creates VXLAN interfaces: vxlan10001, vxlan10002, vxlan10100
  • Creates per-VNI bridges: br-vxlan10001, br-vxlan10002, br-vxlan10100
  • Attaches VXLAN to bridges with proper flags (nolearning)
  • Idempotent (checks before creating)
Execution: Bash script, must be executable
Deploy to: /opt/frr/setup-vtep.sh
Called by: systemd ExecStartPre=/opt/frr/setup-vtep.sh
Permissions: chmod +x (executable)


Dockerfile (FRR)
────────────────
Purpose: Build FRR from source (host-a)
Content:
  • Multi-stage build (builder + runtime)
  • Base: Ubuntu 24.04
  • Installs build tools, compiles FRR from /src/frr
  • Copies FRR binaries to runtime container
  • Installs configuration files
Build: docker build -t frr:unheaded -f routing/frr/Dockerfile .
Run: docker run --net=host -v /etc/frr:/etc/frr:ro frr:unheaded
Ports: 2601-2610 (exposed, not used in network namespace mode)


bird.conf
──────────
Purpose: Main BIRD routing daemon configuration (host-b)
Content:
  • Device and direct protocol definitions
  • Kernel protocol (IPv4/IPv6 sync with bidirectional learning)
  • BFD protocol (300ms intervals, multiplier 3)
  • Static routes (service subnets)
  • BGP session to host-a (AS65001, iBGP peer)
  • EVPN address family (Type-2, Type-5 routes)
  • OSPF v3 (optional, for intra-host routing)
  • Router Advertisement (SLAAC for containers on fd00:dead:beef:2::/64)
  • Filters for IPv4/IPv6 exports
Syntax: BIRD configuration language
Deploy to: /etc/bird/bird.conf
Test with: birdc


bird-env
─────────
Purpose: BIRD environment variables (host-b)
Content:
  • BIRD_OPTS: daemon startup options
  • BIRD_LOG_LEVEL: logging verbosity
  • BIRD_LOG_FILE: output path
  • BIRD_PIDFILE: process ID file location
  • ENABLE_IPV6: IPv6 support flag
Format: Shell environment variables
Deploy to: /etc/bird/bird-env (or source in systemd)
Usage: source /etc/bird/bird-env (or ExecEnvironmentFile=)


bird-check.sh
──────────────
Purpose: BIRD connectivity verification (host-b)
Content:
  • Shows protocol status: birdc show protocols all
  • Shows BGP session: birdc show protocols forge
  • Shows learned routes: birdc show route protocol forge
  • Shows IPv6 routes: birdc show route where net ~ fd00:dead:beef::/32
  • Shows BFD sessions: birdc show bfd sessions
  • Shows kernel routes: ip -6 route show | grep dead:beef
Execution: Bash script, must be executable
Deploy to: /opt/bird/bird-check.sh or ~/bin/
Usage: ./bird-check.sh
Output: Real-time status of BGP peering, routes, BFD
Permissions: chmod +x (executable)

TROUBLESHOOTING FILE PATHS
================================================================================

FRR Log Files:
  /var/log/frr/bgpd.log ................... BGP protocol logs
  /var/log/frr/isisd.log .................. IS-IS protocol logs
  /var/log/frr/bfdd.log ................... BFD logs
  /var/log/frr/zebra.log .................. Zebra kernel interface logs
  /var/log/frr/frr.log .................... General FRR logs

BIRD Log Files:
  /var/log/bird/bird.log .................. All BIRD logs
  /var/log/syslog or /var/log/messages ... BIRD syslog entries

Configuration Paths:
  /etc/frr/ .............................. FRR config directory
  /etc/bird/ ............................. BIRD config directory
  /etc/systemd/system/frr.service ........ FRR systemd unit
  /etc/systemd/system/bird.service ....... BIRD systemd unit

Runtime Paths:
  /var/run/frr/ .......................... FRR runtime sockets, PID
  /var/run/bird/ ......................... BIRD runtime sockets, PID
  /var/run/frrvty/ ....................... FRR vtysh socket
