IMPORT OPTIONS (4 methods):

1. GRAFANA UI (Manual)
   Steps:
     1. Open Grafana: http://localhost:3000
     2. Dashboards → Import
     3. Upload JSON file
     4. Select "Prometheus" datasource
     5. Click "Import"
   Time: 2-3 minutes per dashboard

2. PROVISIONING (Automatic)
   Steps:
     1. Copy all *.json files to /etc/grafana/provisioning/dashboards/
     2. Restart Grafana: systemctl restart grafana-server
     3. Dashboards load automatically
   Time: 1 minute total
   Note: Prometheus datasource must be provisioned separately

3. API (Scripted)
   Example:
     curl -X POST http://localhost:3000/api/dashboards/db \
       -H "Authorization: Bearer $TOKEN" \
       -H "Content-Type: application/json" \
       -d @01_host_overview.json
   Time: 1 minute total

4. DOCKER (Container Volumes)
   Example:
     docker run -d \
       -v /path/to/dashboards:/etc/grafana/provisioning/dashboards \
       grafana/grafana:10.0
   Time: 1 minute total

RECOMMENDED DEPLOYMENT: Method 2 (Provisioning) for production

MONITORING WORKFLOWS:

Daily Operations:
  • Host Overview: Check infrastructure status (CPU, memory, disk)
  • Services: Monitor service health and error rates
  • eBPF: Check packet drop rates and latency

Performance Analysis:
  • LLM Inference: Monitor token throughput and VRAM utilization
  • gRPC Latency: Analyze P50/P95/P99 latency trends
  • Network: Review throughput and RTT trends

Troubleshooting:
  • eBPF Pipeline: Identify high drop rates or latency
  • WireGuard: Check encryption overhead and peer status
  • Services: Identify failing services and high restart counts

ALERT RULES (Recommended):

Critical (immediate action):
  • Host CPU >90% for 5 min
  • Memory >90% for 5 min
  • Service down (up=0)
  • XDP drop rate >80% for 5 min

Warning (within 1 hour):
  • Host CPU 70-90% for 10 min
  • gRPC errors >5/sec
  • Service restarts ≥3 in 1 hour
  • VRAM >90% for 5 min

No Data Appearing?

  2. Verify metrics: curl http://prometheus:9090/api/v1/label/__name__/values
  3. Check datasource configuration in Grafana
  4. Verify scrape configs include all exporters

Missing Panels?
  1. Verify metrics exist: curl http://prometheus:9090/api/v1/query
  2. Check label names match exporter output
  3. Test queries directly in Prometheus UI

Performance Issues?
  1. Reduce time range from 1 hour to 15 minutes
  2. Increase Prometheus query timeout
  3. Consider increasing scrape intervals

Query Errors?
  1. Copy query to Prometheus UI and test
  2. Check metric names for typos
  3. Verify label names match available labels
