INSTALLATION METHODS
====================

Method 1: Grafana UI (Manual)
  1. Open Grafana: http://localhost:3000
  2. Click Dashboards → Import
  3. Paste JSON content or upload file
  4. Select "Prometheus" datasource
  5. Click Import
  6. View dashboard

Method 2: Provisioning (Automatic)
  1. Copy all *.json files to /etc/grafana/provisioning/dashboards/
  2. Restart Grafana: systemctl restart grafana-server
  3. Dashboards load automatically on startup
  4. Prometheus datasource must be provisioned separately

Method 3: API (Scripted)
  curl -X POST http://localhost:3000/api/dashboards/db \
    -H "Authorization: Bearer $TOKEN" \
    -H "Content-Type: application/json" \
    -d @/path/to/dashboard.json

Method 4: Docker Volumes
  docker run -d \
    -v /path/to/dashboards:/etc/grafana/provisioning/dashboards/unheaded \
    grafana/grafana:10.0


TROUBLESHOOTING
===============

No Data Appearing?
  1. Check Prometheus connectivity
  2. Verify metrics in Prometheus UI: http://prometheus:9090
  3. Confirm exporters are running and scraping
  4. Check datasource UID is "prometheus"

Missing Panels?
  1. Verify required metrics exist in Prometheus
  2. Check labels match exporter configuration
  3. Use Prometheus query builder to test queries

Time Issues?
  1. Ensure NTP synchronization on all hosts
  2. Verify Grafana timezone settings
  3. Check Prometheus scrape intervals

JSON Validation?
  1. All 5 JSON files validated as valid Grafana v10 format
  2. All queries tested against Prometheus API
  3. All panels use correct timeseries/gauge/stat types
