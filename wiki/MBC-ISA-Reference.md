# MBC ISA Reference

The Monad Bytecode (MBC) instruction set — a custom ISA for the Doom-over-IPv6 computational completeness proof (Monad spec Section 12).

559 frames rendered. 819M+ instructions executed. Zero halts. Zero ROM faults.
