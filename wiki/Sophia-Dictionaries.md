# Sophia Dictionaries

Tree-structured BPF maps providing exponent-encoded field lookups. 1 byte = 256 meanings. O(1) lookup per field.

Sophia dictionaries allow the 20-byte Monad to carry rich semantic meaning in compact form by mapping byte values to pre-agreed definitions stored in BPF maps on each hop.
