# Skills — AI Agent Specializations

Unheaded uses 16 specialized AI agent skills for development, operations, and documentation. Each skill is a focused persona with domain expertise and protocol awareness.

## Skill Catalog

### Leadership & Coordination

| Skill | Role | Triggers |
|-------|------|----------|
| **Captain** | CEO/CMO/CFO/CHRO/CPO fusion. Strategy, vision, business narrative | vision, strategy, funding, pitch, brand, hiring |
| **Micromanager** | VP Eng + CTO + Staff TPM. Execution, QA, Kanban, security ethics | roadmap, milestone, sprint, backlog, ship, QA |
| **Busboy** | Office manager / coordinator. Bridges technical and business talk | help, confused, stuck, coordinate, clarify, sync |
| **Round Table** | War council. Summons ALL skills for major reviews and decisions | round table, war council, all hands, major decision |

### Technical Implementation

| Skill | Role | Triggers |
|-------|------|----------|
| **Architect** | 4× staff architect fusion (Linux, Network, Infra, Security) | infrastructure, platform, NixOS, eBPF, BGP, VXLAN |
| **Developer** | Security-first Go + Rust developer. Strict TDD, defensive coding | code, implement, test, TDD, Go, Rust, wire format |
| **Scientist** | 40+ elite minds fusion. Theory, hypothesis, formal verification | theory, prove, analyze, algorithm, optimize, root cause |
| **RFC Editor** | IETF-track RFC authoring. BCP 14, IANA, wire format specs | RFC, Internet-Draft, IANA, BCP 14, wire format spec |

### Lore & Navigation

## Protocol Awareness

All skills understand the core protocol stack: Monad wire format (20-byte register file), Sophia BPF dictionaries, Wotan memory model, Anamnesis event tracing, Shield/Shim eBPF pipeline, and Kingdom Mode extended register space.

## Skill Bundles

Packaged `.skill` bundles for all 16 skills are available in `skills/` for import into new agent sessions.
