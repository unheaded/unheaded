## Shared Package Reference (New in Session 5)

### `pkg/httputil` — Unified HTTP Response Envelope

All migrated services now use this standard format:

**Success:**
```json
{"success": true, "data": {...}, "meta": {"timestamp": "2026-02-09T..."}}
```

**Error:**
```json
{"success": false, "error": {"code": "NOT_FOUND", "message": "...", "details": "..."}, "meta": {"timestamp": "..."}}
```

**API:**
```go
import "unheaded/pkg/httputil"

httputil.WriteSuccess(w, http.StatusOK, data)
httputil.WriteError(w, http.StatusBadRequest, "INVALID", "bad input")
httputil.WriteErrorWithDetails(w, 500, "INTERNAL", "failed", err.Error())
httputil.WriteJSON(w, status, anyStruct)  // no envelope, raw JSON

// Request body parsing
var req MyStruct
if err := httputil.DecodeJSONBody(r, 0, &req); err != nil {
    httputil.HandleRequestError(w, err)
    return
}
```
