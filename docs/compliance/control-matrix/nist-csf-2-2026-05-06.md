# NIST Cybersecurity Framework 2.0 Coverage Matrix

**Date:** 2026-05-06
**Author:** Marshal post-shift extension (NORTH-STAR Appendix A Phase E9)
**Reference:** NIST CSF 2.0 (February 2024) — 6 Functions × Categories × Subcategories
**Status legend:** **MAPPED** = full coverage with evidence | **PARTIAL** = some coverage, gap noted | **GAP** = no kingdom work yet | **N/A** = not applicable | **DEFERRED** = planned, not shipped | **UNVERIFIED** = MoatGhost confirm

**Kingdom posture:** CSF 2.0 added the **GOVERN (GV)** function in 2024, elevating governance from a category in IDENTIFY to a peer function. The kingdom is **strong on PROTECT + DETECT** (engineering-driven), **weak on GOVERN + RESPOND + RECOVER** (organizationally-driven). This is the same shape that emerges in every other framework matrix tonight; CSF 2.0 makes it sharpest.

**Profile target:** an Implementation Tier between **Tier 2 (Risk Informed)** and **Tier 3 (Repeatable)** is realistic for the engineering-side controls; **Tier 1 (Partial)** is honest for the governance-side controls until headcount.

## Headline gaps (priority for CSF 2.0 maturation)

1. **GOVERN function (almost entirely GAP)** — single-operator-kingdom posture document closes most of GV.RR + GV.OV; risk register closes GV.RM.
2. **RESPOND + RECOVER functions (almost entirely GAP)** — IR plan + recovery runbook closes ~20 subcategories across two functions.
3. **DE.AE-04 / DE.AE-08 incident-criteria + impact-estimation** — pairs with RESPOND closure.
4. **PR.AA-05 least privilege failure** — tonight's K8s RBAC review F1.
5. **PR.DS-01 at-rest encryption** — The Well + etcd not encrypted-at-rest.
6. **GV.SC-08 supplier IR coordination** — depends on IR plan.

## Strongest mapped functions

PROTECT and DETECT — these are where the kingdom genuinely earns CSF 2.0 readiness. Roughly 70-80% MAPPED at subcategory level in those two functions.

## Implementation Tier estimate

| Function | Realistic Tier today | Path to next |
|----------|----------------------|---------------|
| GOVERN | Tier 1 (Partial) | Risk-mgmt strategy doc + accountability matrix → Tier 2 |
| IDENTIFY | Tier 2 (Risk Informed) | Vulnerability disclosure program + criticality ranking → Tier 3 |
| PROTECT | Tier 3 (Repeatable) | Close at-rest encryption + RBAC tighten → Tier 4 (Adaptive) |
| DETECT | Tier 3 (Repeatable) | SIEM correlation + impact-estimation method → Tier 4 |
| RESPOND | Tier 1 (Partial) | IR plan → Tier 2 |
| RECOVER | Tier 1 (Partial) | DR runbook + RPO/RTO → Tier 2 |

Aggregate: between Tier 2 and Tier 3, with a substantial GOVERN/RESPOND/RECOVER weight pulling the average down.
