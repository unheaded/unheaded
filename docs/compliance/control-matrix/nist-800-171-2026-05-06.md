# NIST SP 800-171 r3 Control-Coverage Matrix (CUI Protection)

**Date:** 2026-05-06
**Author:** Marshal post-shift extension (NORTH-STAR Appendix A Phase E7)
**Reference:** NIST SP 800-171 Revision 3 (May 2024) — Protecting Controlled Unclassified Information in Nonfederal Systems and Organizations
**Status legend:** **MAPPED** = full coverage with evidence | **PARTIAL** = some coverage, gap noted | **GAP** = no kingdom work yet | **N/A-DESIGN** = not applicable by Unheaded's architectural posture | **ADOPTER-OWNS** = adopter responsibility | **DEFERRED** = planned, not shipped | **UNVERIFIED** = MoatGhost confirm | **PARAM-GAP** = covered but parameter value not met

**Kingdom posture:** Unheaded is **never itself in CUI scope** by design. Unheaded does not store, process, or transmit CUI. The matrix below is most useful for **(a) DoD / DFARS adopters** who would deploy Unheaded into a CUI environment and need to know what controls Unheaded itself contributes, and **(b) the foundation for CMMC 2.0 Level 2 mapping** (E13).

**Critical framing:** 800-171 r3 includes **110 security requirements** across 17 families, plus 60+ Organization-Defined Parameters (ODPs) where the implementing organization specifies values. Many controls below mirror 800-53 Moderate equivalents; this matrix focuses on 800-171-specific framing and the requirements organization (vs. 800-53's larger catalog).

## Headline gaps (priority for any DoD adopter / DFARS pipeline)

1. **03.06 Incident Response family (entire family GAP)** — single IR plan closes 5 controls across this matrix + cross-framework gaps.
2. **03.05.03 MFA (UNVERIFIED → likely PARAM-GAP)** — DFARS requires MFA on privileged + remote-access accounts. Need explicit attestation.
3. **03.13.11 FIPS 140-3 validated cryptographic module** — cloudflare/circl track must be confirmed against current FIPS 140-3 module list (cross-ref FedRAMP SC-13).
4. **03.01.05 / RBAC over-grant (F1 from tonight)** — least-privilege fail blocks DFARS least-privilege requirement.
5. **03.01.09 System Use Notification banner** — federal-form CUI banner required.
6. **03.13.08 At-rest encryption** — The Well + etcd encryption-at-rest not wired (cross-ref tonight's K8s threat model §3.2).
7. **03.12.02 POA&M tracker** — DFARS contracts often require POA&M reporting.

## Strongest mapped families for DFARS / 800-171

03.01 (AC), 03.03 (AU), 03.04 (CM), 03.05 (IA), 03.13 (SC), 03.14 (SI), 03.17 (SR) — same as 800-53. The seven-family bedrock holds.

## Cross-reference

- **CMMC 2.0 Level 2 (E13)** is built directly on top of this matrix. Closing 800-171 r3 = closing CMMC L2 prerequisites.
- **FedRAMP Moderate (E6)** has substantial overlap; 800-171 is a strict subset focused on CUI-protection scoping.
- **800-53 Rev 5 (E5)** is the parent catalog 800-171 selects from; consult E5 for full enhancement detail.
