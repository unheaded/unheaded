# ISO/IEC 27001:2022 + 27002:2022 Control-Coverage Matrix

**Date:** 2026-05-06
**Author:** Marshal post-shift extension (NORTH-STAR Appendix A Phase E11)
**Reference:** ISO/IEC 27001:2022 (Information Security Management System) + ISO/IEC 27002:2022 (93 controls in 4 themes)
**Status legend:** **MAPPED** = full coverage with evidence | **PARTIAL** = some coverage, gap noted | **GAP** = no kingdom work yet | **N/A** = not applicable | **DEFERRED** = planned, not shipped | **UNVERIFIED** = MoatGhost confirm

**Kingdom posture:** ISO 27001 demands a **formal Information Security Management System (ISMS)** — process discipline first, controls second. The kingdom's 27002 controls (Annex A) are in better shape than its 27001 ISMS clauses (4-10). Roughly **45-55% of Annex A MAPPED or PARTIAL**, but the **ISMS clauses themselves are largely GAP** for a single-operator kingdom. This is the same shape as SOC 2 CC1 / NIST CSF GOVERN.

A formal **ISO 27001:2022 certification** requires a Stage 1 (documentation review) + Stage 2 (operational audit) by an accredited certification body. Realistically 12-18 months from where the kingdom is today; the **42 ISO 27002:2022 attributes** (e.g. control type, info-security property, cybersecurity concept, operational capability, security domain) require multi-axis tagging that doesn't exist yet.

## Headline gaps for ISO 27001:2022 readiness

1. **ISMS clauses 4-10 (Context, Leadership, Planning, Support, Operation, Performance evaluation, Improvement)** — these are management-system requirements, not technical. Single-operator-kingdom posture document closes most.
2. **A.5.24-A.5.30 incident management + business continuity** — close with one IR plan + one BC plan + DR runbook (universal across all frameworks).
3. **A.5.12 / A.5.13 information classification + labelling** — single page + label scheme; closes a category of follow-on controls.
4. **A.6 People controls (entire theme)** — single-operator-kingdom posture document.
5. **A.5.10 Acceptable Use Policy** — single document.
6. **A.8.10 Information deletion** — pairs with retention policies cross-framework.

## Strongest mapped areas

A.8 Technological controls is where the kingdom's bedrock lives. Roughly 70% of A.8 is MAPPED or PARTIAL. Lead-with-strength for any ISO 27001 readiness narrative.

## Stage 1 → Stage 2 audit timeline

A realistic ISO 27001:2022 certification path:

- **Months 0-3:** ISMS scope statement + IS policy authoring (clauses 4-7).
- **Months 3-6:** Risk assessment + risk treatment plan (clause 8.2/8.3); Statement of Applicability (SoA) for the 93 Annex A controls.
- **Months 6-9:** ISMS operation + internal audit + management review (clauses 8/9).
- **Months 9-12:** Stage 1 audit (documentation review).
- **Months 12-15:** remediation + Stage 2 audit (operational).
- **Month 15-18:** certification.

Tonight's matrix is **month 0**.
