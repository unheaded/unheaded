# CMMC 2.0 Level 2 Coverage Matrix

**Date:** 2026-05-06
**Author:** Marshal post-shift extension (NORTH-STAR Appendix A Phase E13)
**Reference:** Cybersecurity Maturity Model Certification (CMMC) 2.0 (Final Rule, 32 CFR Part 170, Effective December 16, 2024) — Level 2 (Advanced)
**Status legend:** **MAPPED** = full coverage with evidence | **PARTIAL** = some coverage, gap noted | **GAP** = no kingdom work yet | **N/A** = not applicable | **DEFERRED** = planned, not shipped | **UNVERIFIED** = MoatGhost confirm

**Approach:** CMMC 2.0 Level 2 = **all 110 practices from NIST SP 800-171 r2** (note: r2 baseline, not r3 — DoD has not yet updated CMMC to r3 as of this writing) + **CMMC-specific assessment / governance process**. The control-content matrix is in `nist-800-171-2026-05-06.md` (E7); this document covers the **CMMC-specific delta**.

**Critical distinction:** unlike SSDF self-attestation, CMMC Level 2 requires **third-party assessment** for many DoD contracts (the threshold depends on contract type — "self-assessment" Level 2 vs "C3PAO-assessed" Level 2). The C3PAO assessment + DoD AO sponsorship is the gating constraint, not the technical controls.

## CMMC 2.0 Level Hierarchy

| Level | Name | Practices | Assessment | Use Case |
|-------|------|-----------|------------|----------|
| Level 1 | Foundational | 17 (FAR 52.204-21) | Annual self-assessment | FCI (Federal Contract Information) |
| **Level 2** | **Advanced** | **110 (NIST 800-171 r2)** | **Triennial C3PAO OR self-assessment depending on contract** | **CUI** |
| Level 3 | Expert | 110 + ~24 (NIST 800-172) | Triennial DIBCAC | Critical CUI |

The kingdom would target **Level 2** if any DoD adopter is in scope.

### Plan of Action and Milestones (POA&M) — CMMC restrictions

CMMC 2.0 introduces **practice-level POA&M restrictions** — some practices must score 5 (the highest weight) and **cannot be POA&M'd** (i.e., must be implemented before assessment, not deferred). The 5-weighted-must-be-implemented practices include:

| Practice | Title | Kingdom Status |
|----------|-------|-----------------|
| 03.05.03 (NIST r2: 3.5.3) | Multi-factor authentication | UNVERIFIED — must verify enforcement |
| 03.13.11 (NIST r2: 3.13.11) | FIPS-validated cryptography | PARAM-GAP — cloudflare/circl FIPS-track but not 140-3 module-validated |
| 03.13.16 (NIST r2: 3.13.16) | Protect confidentiality of CUI at rest | PARTIAL → GAP for The Well + etcd at-rest encryption |

These three are the single highest-leverage technical gaps for any CMMC Level 2 adopter using Unheaded.

POA&M-eligible practices can have plans for closure (180 days max). Ineligible (5-weighted) practices cannot.

## Headline gaps for CMMC Level 2 self-assessment readiness

1. **MFA enforcement (3.5.3)** — must be enforceable on all privileged + remote-access accounts (5-weighted, no POA&M).
2. **FIPS 140-3 validated cryptographic module (3.13.11)** — verify or replace cloudflare/circl with a 140-3-validated path (5-weighted, no POA&M).
3. **CUI at-rest encryption (3.13.16)** — wire The Well + etcd at-rest encryption (5-weighted, no POA&M; cross-ref tonight's K8s threat model §3.2).
4. **IR plan (cross-framework universal)** — closes 03.06 IR family + 5+ other framework gaps.
5. **SSP authoring** — built on tonight's matrix; ~3-4 weeks of MoatGhost time.
6. **Asset categorization (CUI Asset, Security Protection Asset, etc.)** — single document for assessment readiness.

## CMMC Level 2 timeline

If a DoD adopter pulls Unheaded into a CUI environment:

- **Months 0-3:** SSP authoring + scope definition + asset categorization.
- **Months 3-6:** Close the three 5-weighted gaps (MFA, FIPS, at-rest encryption).
- **Months 6-9:** C3PAO selection (if assessed) OR self-assessment + SPRS upload (if self-assessed).
- **Months 9-12:** Assessment.
- **Year 4+:** Triennial reassessment.

Tonight's matrix is **month 0**.
