#### Auto-Sync Behavior

- On startup: initial sync from stored timeline
- On `timeline.md` file change: watcher triggers reload + auto-sync
- On milestone update: `HandleUpdateMilestone` triggers auto-sync
- `SyncDir` defaults to `filepath.Dir(TimelinePath)` — in Docker, this is `/data/`

#### Docker Behavior Note

`timeline.md` is mounted `:ro` in docker-compose.yml (`./references/timeline.md:/data/timeline.md:ro`). The sync endpoint correctly writes JSON/TOML/YAML to `/data/` but **cannot overwrite timeline.md** — this is correct behavior (source of truth is read-only in the container).
