## IMPORTANT PATTERNS

### Logger API (Fluent Style)

```go
// CORRECT
d.log.Info().Str("id", id).Msg("Container created")
d.log.Error().Err(err).Str("id", id).Msg("Failed to create")

// WRONG (will not compile)
d.log.Info("message", "key", value)
```

### Wotan Client

```go
client, err := wotanClient.NewClient(wotanAddr)
if err != nil {
    // Gracefully degrade - continue without Wotan
    log.Warn().Err(err).Msg("Wotan unavailable")
}
defer client.Close()

// Publish
client.Publish(ctx, "topic.name", payload)

// Subscribe
client.Subscribe(ctx, "topic.pattern")
```
