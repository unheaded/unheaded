### CRITICAL: Spec-Implementation Alignment Fix

**Discovery:** Field layout divergence between draft-03 and monad-common/src/lib.rs

**Root Cause:** The implementation removed `trace_id` (4 bytes), replacing it with IPv6 Flow Label (RFC 6437) for tracing. The old spec still listed trace_id at bytes 0x04-0x07.

**Decision:** Update spec to match implementation (implementation is ground truth).

**Fix Applied:**
- Removed trace_id field (was 0x04-0x07, 4 bytes)
- Shifted all subsequent fields down 4 bytes
- Added new fields: src_prefix_lo, dst_prefix_lo, scratch[0-3]
- Updated scratch region (was reserved, now used for scratch[0-3])

Git commit: `8859a81: docs(protocol): align draft-03 field layout with monad-common implementation`

## Field Layout Changes — Critical Reference

### OLD Spec Layout
```
0x00-0x03: flow_label (3B) + flags (1B)
0x04-0x07: trace_id (4B) ← REMOVED
0x08: qos_class (1B)
0x09: flow_action (1B)
0x0A: circuit_state (1B)
0x0B: flags (1B) — K1, K0 fields
0x0C: latency_budget_us (2B)
0x0E: deployment_ring (1B)
0x0F: mesh_flags (1B)
0x10-0x11: reserved (2B)
0x12-0x13: checksum (2B) — CRC-16 of bytes 0x00-0x11
```

### NEW Spec Layout (= Implementation)
```
0x00-0x03: flow_label (3B) + flags (1B)
0x04: qos_class (1B)                           [shifted from 0x08]
0x05: flow_action (1B)                         [shifted from 0x09]
0x06: circuit_state (1B)                       [shifted from 0x0A]
0x07: flags (1B) — CUSTOM, RSVD (not K1/K0)   [shifted from 0x0B]
0x08-0x09: latency_hint (2B)                   [shifted from 0x0C, renamed]
0x0A: deploy_ring (1B)                         [shifted from 0x0E, renamed]
0x0B: mesh_flags (1B)                          [shifted from 0x0F]
0x0C: src_prefix_lo (1B)                       [NEW]
0x0D: dst_prefix_lo (1B)                       [NEW]
0x0E-0x11: scratch[0-3] (4B)                   [NEW, was reserved]
0x12-0x13: checksum (2B)                       [CRC-16 of bytes 0x00-0x11]
```

**Critical Note:** CRC covers bytes 0x00-0x11 (18 bytes total). Checksum stored at 0x12-0x13.

---

### Flag Field Changes (0x07 and 0x00 bits)

**Old flags bit meanings:**
- K1, K0 (Kingdom bits)
- T (TRACED)
- E (ENCRYPT)

**New flags bit meanings:**
- CUSTOM (bit 6, 0x40)
- RSVD (bit 7, 0x80)
- T (TRACED) — still present
- E (ENCRYPT) — still present

**8-Layer Mitigation Strategy:**

2. State machine design (eliminate complexity)

6. Bounded array access (no loops over maps)
7. Verifier-friendly patterns (documented)

## Critical Protocol Notes for Next Agent

### Ground Truth
**monad-common/src/lib.rs** is the canonical source for wire format. The spec (draft-03) now matches it exactly. Do NOT reference old traces mentioning trace_id.

### Field Layout
- Total header: 20 bytes (0x00-0x13)
- CRC covers: 18 bytes (0x00-0x11)
- Checksum location: 0x12-0x13
- All fields byte-aligned

### Offset Shifts (Due to trace_id removal)
All fields after 0x03 shifted down 4 bytes. If you see old offsets in comments or logs, add 4 to the new offset:
- Old 0x08 (qos_class) → New 0x04
- Old 0x0C (latency_budget_us) → New 0x08 (latency_hint)
- Old 0x0E (deployment_ring) → New 0x0A (deploy_ring)
- Old 0x0F (mesh_flags) → New 0x0B
- Old 0x10-0x11 (reserved) → New 0x0E-0x11 (scratch[0-3])

### New Fields
- src_prefix_lo (0x0C) — Lower byte of IPv6 source prefix
- dst_prefix_lo (0x0D) — Lower byte of IPv6 destination prefix
- scratch[0-3] (0x0E-0x11) — 4-byte scratch space (not used in current spec, available for future extensions)
