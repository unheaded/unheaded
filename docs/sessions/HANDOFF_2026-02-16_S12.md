### 3-Service Integration
```

Timeguru (:8000) ←→ Kanban (:8081)
    timeline.updates topic      SSE → browser
```

### Transport State Machine
```
Startup → ProbeGRPC()
    ├─ healthy → TransportGRPC (primary)
    └─ unhealthy → TransportHTTP (degraded)

Runtime:
    gRPC fails mid-stream → degradeToHTTP() (circuit breaker)
    Periodic ProbeGRPC() → re-promote if recovered
```
