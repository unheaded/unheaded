     * Detects any IPv6 HbH extension header (next-header 0x00)
   - SID 9000002: Anomaly detection - CRC mismatch
     * dsize > 1500 bytes (unexpected payload length)
     * Classtype: protocol-command-decode
   - SID 9000010: Epoch value anomaly
     * Detects time desynchronization or spoofing
     * Classtype: protocol-command-decode
   - SID 9000011: Sequence number anomaly
     * Detects out-of-order packets or packet loss
     * Classtype: protocol-command-decode
   - SID 9000030: Replay attack detection
     * threshold: 1000+ HbH packets in 1 second from single source
     * track: by_src (source IP-based tracking)
     * Classtype: denial-of-service
   - SID 9000031: Scanning behavior
     * threshold: 20+ different destinations in 5 seconds
     * Detects network reconnaissance attempts
     * Classtype: network-scan
   - SID 9000099: Unknown opcode
     * Detects protocol abuse or fuzzing attempts
     * Classtype: protocol-command-decode
   All rules use ipv6-exthdr: hbh matcher (does NOT modify packets)

================================================================================
ARCHITECTURE CONSTRAINTS
================================================================================

GPL-2.0 Isolation:
- Suricata runs in container/LXD with GPL-2.0 license (GPL-2.0)
- Non-GPL services (Go binaries) read EVE JSON file and unix socket
- No static linking between GPL and non-GPL code
- Data boundary: EVE JSON REST API only

IPv6 HbH (Hop-by-Hop) Options:
- Monad protocol encodes data in IPv6 extension headers
- Next-header: 0x00 (IPPROTO_HOPOPTS)
- Wire format: 20-byte option block
- CRITICAL: decode-events: no prevents stripping by Suricata

High-Performance Packet Capture:
- AF_PACKET mode on eth1 for L2 packet capture
- tpacket-v3: High-performance kernel ring buffers
- mmap: Memory-mapped capture buffer
- cluster_flow: Load balancing across CPU threads
- cluster-id: 99 (coordination with Shield eBPF)

eBPF Integration:
- Suricata: /sys/fs/bpf mapped read-write
- Shield: eBPF programs in same /sys/fs/bpf namespace
- Allows shared BPF maps between IDS and packet filter
