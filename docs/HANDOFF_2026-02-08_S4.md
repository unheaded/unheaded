## What Session 4 Shipped

### 1. Anamnesis Data Race Fix (P0 — RESOLVED)

**File:** `services/anamnesis/anamnesis_test.go`

**Root Cause:** `TestRegisterEventHandler` used bare `bool` + `*Event` variables written by an async handler goroutine (spawned by `go s.notifyHandlersSnapshot()` at `anamnesis.go:258`), then read those variables after only a `time.Sleep(50ms)`. `time.Sleep` is NOT a synchronization primitive — no happens-before relationship in Go's memory model. Race detector correctly flagged it.

**Fix:** Replaced with buffered `chan *Event`. Handler sends event into channel, test receives via `select` with 2-second timeout. Channel send→receive creates proper happens-before per Go memory model. Production code (`notifyHandlersSnapshot`) untouched — the async design is correct.

**Before (racy):**
```go
handlerCalled := false
var capturedEvent *Event
svc.RegisterEventHandler(func(ctx context.Context, event *Event) error {
    handlerCalled = true        // WRITE from goroutine 73
    capturedEvent = event       // WRITE from goroutine 73
    return nil
})
svc.Append(ctx, "service-1", "Service", EventCreated, map[string]interface{}{"test": true})
time.Sleep(50 * time.Millisecond) // NOT synchronization!
if !handlerCalled {              // READ from goroutine 72 — RACE
```

**After (sound):**
```go
done := make(chan *Event, 1)
svc.RegisterEventHandler(func(ctx context.Context, event *Event) error {
    done <- event               // SEND = happens-before
    return nil
})
svc.Append(ctx, "service-1", "Service", EventCreated, map[string]interface{}{"test": true})
select {
case capturedEvent := <-done:   // RECEIVE = synchronized
    if capturedEvent == nil { t.Error("expected event") }
case <-time.After(2 * time.Second):
    t.Fatal("handler was not called within timeout")
}
```
