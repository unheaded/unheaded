### `e4e1e08` — Eliminate data races, add closed-store guard, isolate test DBs

Four categories of test failures fixed after first `-race` run:

1. **Task snapshot pattern** — `taskSnap := *task` value-copy before goroutine in all 3 CRUD methods. Prevents race between async `json.Marshal` and caller mutating the pointer post-return.

2. **Mock lock gap** — `StreamMessages` in `pkg/wotan-client/mock/mock.go` was reading `sub.Status` outside RLock scope while `ApproveSubscription` wrote it under Lock. Fix: read `status = sub.Status` while still holding RLock.

3. **Test isolation** — All test servers now use `t.TempDir()` for DataDir, preventing cross-test SQLite contamination. The shared `./data/kanban.db` was causing 409 conflicts and unexpected seed counts.

4. **Store-aware assertions** — `TestNewServer_ValidConfig` checks `store.TaskCount()` instead of deprecated `len(server.tasks)`. `TestHandleGetTasks_EmptyTasksList` creates bare server with no Store.

5. **Closed-store guard** — `ErrStoreClosed` sentinel error, `closed bool` field, `checkOpen()` helper called inside lock on all 6 public Store methods. `Close()` sets flag under write lock, idempotent double-close.

### Store Safety Model

```
Every public Store method:
  1. Acquire lock (RLock for reads, Lock for writes)
  2. checkOpen() → ErrStoreClosed if db==nil || closed
  3. Execute SQL
  4. Unlock

Close():
  1. Acquire write lock
  2. If already closed → return nil (idempotent)
  3. Set closed = true
  4. db.Close()
  5. Unlock
```

No TOCTOU gap — the closed check happens inside the same lock acquisition as the operation.
