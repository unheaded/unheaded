# Tabletop 2026-10-27: the Wotan OOM silent outage, replayed against IR plan v2

**Status:** draft (desk exercise written by an agent from the record; Stevie has not run it)
**Plan under test:** [IR plan v2](../../runbooks/security/ir-plan-v2-2026-10-27.md)
**Incident replayed:** [2026-10-18 Wotan OOM-killed, down 10 hours](2026-10-18-wotan-oom-silent-outage.md)
**Kind:** simulated. Nothing was run against west or east.

## Scenario

2026-10-18 06:42 UTC (a Sunday, 01:42 in Austin). Wotan on west is OOM-killed at its 256 MiB limit. Restart policy `no`. Every service keeps running and publishes into nothing. As it happened, nobody noticed for about ten hours.

The replay asks, for each phase: what v2 says, what would actually happen with what is in the repository today, and what is missing. "Today" means develop at 2026-10-27, with the host window E-D not yet run.
