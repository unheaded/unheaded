  ALL 15 SECURITY CONSIDERATIONS FROM SECTION 18 IMPLEMENTED:
  
  PQC-001: SigRef Exhaustion
    - Rate-limit new SigRef allocations (1000/sec max)
    - LRU eviction at 90% capacity
    - Alert at 80% utilization
    
  PQC-002: Cache Poisoning
    - Immutable SigRef-to-sig binding per flow
    - Cryptographic binding: SHA-256(flow_id || epoch || sig)
    - No SigRef reuse within epoch
    
  PQC-003: Timing Oracles
    - Constant-time HashPfx comparison
    - Const-time fingerprint matching
    - Async verification mitigates data plane timing
    
  PQC-004: Replay Attacks
    - SeqNum sliding window (64 packets)
    - Strict monotonic enforcement
    - CAS-based increment
    
  PQC-005: Memory Exhaustion
    - Max map sizes enforced (10M entries)
    - LRU eviction at 90%
    
  PQC-006: HashPfx Collision
    - Documented as integrity check only (NOT security)
    - Full SLH-DSA verification is trust anchor
    
  PQC-007: Async Verification Window
    - PESSIMISTIC mode (safe): hold until verified
    - OPTIMISTIC mode (risky): forward then teardown
    - Default PESSIMISTIC for SOVEREIGN/ENHANCED
    
  PQC-008: Control Plane Compromise
    - Audit trail in Anamnesis (all verifications logged)
    - Shield independent of daemon
    - Out-of-band verification via Wotan
    
  PQC-009: Algorithm Confusion
    - algo_id validation at Shield entry
    - Cross-family mismatch detection
    - Rejection if family changes mid-flow
    
  PQC-010: Side Channels (FN-DSA)
    - Constant-time signing daemon
    - Isolated CPU cores, mlockall
    - No data-dependent branches
    
  PQC-011: Tier Downgrade
    - Anamnesis WARNING on downgrade
    - Admin confirmation required
    - Immutable audit log
    
  PQC-012: Key Revocation Race
    - Atomic batch invalidation
    - Grace period handling
    - Atomic publish to all Shields
    
  PQC-013: Entropy Starvation
    - Runtime entropy monitoring
    - Daemon startup validation
    - Alert if < 256 bits available
    
  PQC-014: Perimeter Isolation
    - Header stripping confines attack surface
    - Wotan state not accessible from data plane
    - eBPF boundary enforcement
