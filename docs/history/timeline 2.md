## The Network Mesh
**"Always Wearing a Full Suit of Armor"**

### The Fundamental Law
> Every component MUST connect to every other component.
> The Knight is NEVER without full armor. No exposed joints. No gaps. Full mesh.

### Mandatory Network Enchantments (Every Component)

**BFD - Bidirectional Forwarding Detection:**
```yaml
Mode: Asynchronous
Intervals: 50-300ms
Multiplier: 3 (failure after 3 missed heartbeats)
Purpose: Sub-second failure detection
```

**BGP Base Layer (ALWAYS ON):**
```yaml
graceful-restart: enabled (tight timers)
add-path: enabled (multiple paths per prefix)
timers: holdtime 9s / keepalive 3s
next-hop-tracking: enabled (immediate withdrawal)
ecmp: enabled (load-share across paths)
dampening: disabled (kills convergence speed)
rpki: enabled (strict validation)
```

**PIC - Prefix Independent Convergence:**
```yaml
pic-edge: enabled
pic-core: enabled
Purpose: Pre-computed backup paths, sub-50ms switchover
```

### Convergence Targets
| Event | Target | Mechanism |
|-------|--------|-----------|
| Link failure | < 50ms | BFD + PIC |
| Node failure | < 100ms | BFD + BGP + PIC |
| Route withdrawal | < 1s | Next-Hop Tracking |
| Full reconvergence | < 10s | Aggressive timers |
