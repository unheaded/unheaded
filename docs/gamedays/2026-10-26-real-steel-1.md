## Scenarios

### Scenario A (headline): canary hurt by real latency, rolled back by Sword

- **Hypothesis**: steady state is p99 < 100 ms on `/` across 3 replicas.
  A canary v2→v3 (healthy build) with latency analysis stays up unless
  hurt; `network_delay` 300 ms on the canary instance alone pushes its p99
  over the 100 ms threshold, so Sword rolls back on its own, the chaos
  experiment closes as "target gone", and v2 x3 keeps serving.
- **Inject**: Sword canary `{"type":"canary","steps":[{"weight":33,"pause":"60s","analysis":true},{"weight":100}],"analysis":{"latency_p99_threshold":"100ms","interval":"30s"}}`; once the canary is healthy, chaos `network_delay` `{delay_ms:300}` on it for 5 min.
- **Success**: Sword status `rolled_back`, reason `analysis_failed` with the measured p99; canary instance deleted; journal entry closed; probes 100 % for 2 min after; availability over A >= 99 %; Kingdom SLOs at pre-flight levels. Record fault start → rollback decision → rollback complete.
- **Watch**: Sword record, chaos journal, `gameday.csv`, `slo:error_ratio:5m`.

### Scenario B: rolling deploy with a replica killed mid-rollout

- **Hypothesis**: Cuirass's enforce loop restarts a killed v2 replica within 90 s and the rolling v2→v3 finishes (or rolls back cleanly) with no orphans.
- **Inject**: Sword rolling v2→v3 (`max_surge 1`, `max_unavailable 0`); when the first v3 is healthy, chaos `container_kill` (`kill`) on one remaining v2.
- **Success**: MTTR recorded; `lxc list --project unheaded` equals Sword's desired set; availability >= 99 %.

### Scenario C (east): service stop under polkit

- **Hypothesis**: `unheaded-timeguru.service` stopped for 60 s is seen by east's Akira and dashboard (read-only GETs) and comes back; nothing else on east changes.
- **Inject**: `service_stop` via the east controller.
- **Success**: unit active afterwards, `/health` 200, journal empty, east unit list = baseline.

### Scenario D: abort drill

- **Inject**: `network_delay` 10 min on a v3 instance, abort via HTTP; again, abort via `/run/unheaded/chaos/ABORT`.
- **Success**: each reverted in <= 5 s; `chaos_aborts_total{path="http"}` = 1 and `{path="file"}` = 1.

### Scenario E (if Phase 13 passed): packet chaos on the lab netns

- **Inject**: `packet_chaos` `delay 100ms` on flow label `0x5EE1` on `steel0-h`.
- **Success**: enrolled flow RTT +100 ms, flow `0x5EE2` unchanged; teardown clean; no program on a physical NIC.
