#   How do I center a div?

 To center a `div` element both horizontally and vertically, you can use several methods depending on your specific requirements. Here are a few common approaches:

### Method 1: Using Flexbox
Flexbox is a powerful layout module that makes it easy to center elements.

```html
<div class="container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh; /* Full viewport height */
}

.centered {
  /* Optional: Add styles for the centered div */
  padding: 20px;
  background-color: lightblue;
  border: 1px solid #000;
}
```

### Method 2: Using Grid Layout
Grid layout is another powerful method for centering elements.

```html
<div class="container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.container {
  display: grid;
  place-items: center;
  height: 100vh; /* Full viewport height */
}

.centered {
  /* Optional: Add styles for the centered div */
  padding: 20px;
  background-color: lightblue;
  border: 1px solid #000;
}
```

### Method 3: Using Absolute Positioning
This method involves using absolute positioning within a relatively positioned parent element.

```html
<div class="container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.container {
  position: relative;
  height: 100vh; /* Full viewport height */
}

.centered {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  /* Optional: Add styles for the centered div */
  padding: 20px;
  background-color: lightblue;
  border: 1px solid #000;
}
```
