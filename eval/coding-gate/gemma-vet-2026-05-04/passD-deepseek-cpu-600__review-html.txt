 The HTML snippet you provided is mostly correct, but there are a few best practices and potential improvements that can be made:

1. **Use `alt` attribute for `img` tags**: The `img` tag should always have an `alt` attribute, even if it's empty. This is important for accessibility.

2. **Consider using `title` attribute**: Adding a `title` attribute can provide additional information when hovering over the link, which can be useful for users.

3. **Avoid inline styles**: While inline styles like `width` can be useful, it's generally better to use CSS for styling.

Here's the improved version of your HTML snippet:

```html
<a href="/dashboard" title="Go to Dashboard">
  <img src="/static/logo.svg" alt="Dashboard Logo" width="120">
  Dashboard
</a>
```

### Explanation:
1. **`alt` attribute**: Added `alt="Dashboard Logo"` to provide alternative text for the image.
2. **`title` attribute**: Added `title="Go to Dashboard"` to provide additional information when hovering over the link.
3. **No inline styles**: The `width` attribute is kept inline for simplicity, but you could move this to a CSS file if you want to manage it more effectively.

This makes the HTML more robust and accessible.
