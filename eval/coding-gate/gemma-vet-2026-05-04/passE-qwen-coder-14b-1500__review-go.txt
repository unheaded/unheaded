```go
package main

import (
    "encoding/json"
    "fmt"
    "os"
)

func saveUser(u User, filePath string) error {
    data, err := json.Marshal(u)
    if err != nil {
        return fmt.Errorf("failed to marshal user: %w", err)
    }

    err = os.WriteFile(filePath, data, 0644)
    if err != nil {
        return fmt.Errorf("failed to write user to file: %w", err)
    }

    return nil
}

func main() {
    user := User{Name: "John Doe", Age: 30}
    err := saveUser(user, "/tmp/user.json")
    if err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Println("User saved successfully")
    }
}
```

### Key Changes:
- **Error Handling**: The errors from `json.Marshal` and `os.WriteFile` are checked and returned as a wrapped error using `fmt.Errorf`.
- **File Path Parameter**: The file path is now a parameter to the `saveUser` function, making it more flexible.
- **Main Function**: Added a `main` function to demonstrate how to use the `saveUser` function and handle potential errors.

This version of the code is more robust and easier to maintain.
