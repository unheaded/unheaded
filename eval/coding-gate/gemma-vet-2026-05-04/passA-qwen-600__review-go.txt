The Go snippet provided has a few issues that need to be addressed:

1. **Error Handling**: The use of `_` to ignore the error from `json.Marshal` and `os.WriteFile` is not a good practice. Ignoring errors can lead to subtle bugs that are hard to debug. Instead, you should handle the errors properly.

2. **File Path**: The file path `/tmp/user.json` is hardcoded. This might not be suitable for all environments, especially in production. Consider using a configuration or environment variable to specify the file path.

3. **File Permissions**: The file permissions `0644` are used, which is fine for a temporary file, but it's good practice to ensure that the permissions are appropriate for your use case.

Here's a revised version of the function with improved error handling and a configurable file path:

```go
package main

import (
    "encoding/json"
    "fmt"
    "os"
)

func saveUser(u User, filePath string) error {
    data, err := json.Marshal(u)
    if err != nil {
        return fmt.Errorf("failed to marshal user: %w", err)
    }

    err = os.WriteFile(filePath, data, 0644)
    if err != nil {
        return fmt.Errorf("failed to write file: %w", err)
    }

    return nil
}

type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

func main() {
    user := User{Name: "John Doe", Age: 30}
    filePath := "/tmp/user.json"

    err := saveUser(user, filePath)
    if err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Println("User saved successfully")
    }
}
```

### Key Changes:
1. **Error Handling**: The function now returns an error if any of the operations fail. This allows the caller to handle the error appropriately.
2. **Configurable File Path**: The file path is now passed as a parameter to the `saveUser` function, making it more flexible.
3. **Error Wrapping**: The errors returned by `json.Marshal` and `os.WriteFile` are wrapped using `fmt.Errorf` to provide more context and make it easier to debug.

This revised version of the function is more robust and easier to maintain.
