#   How do I parse a string to an integer in Rust?

 In Rust, you can parse a string to an integer using several methods provided by the standard library. The most common method is to use the `parse` method, which attempts to parse a string slice into a specified type. Here's a step-by-step guide on how to do this:

Here's an example:

```rust
fn main() {
    let number_str = "42";
    let number: i32 = number_str.parse().expect("Not a valid number");

}
```

- `number_str` is a string slice that contains the number "42".

- `number_str.parse()` attempts to parse the string to an `i32`.
- `expect` is used to handle the case where the parsing might fail, and it will print an error message if the string is not a valid number.
