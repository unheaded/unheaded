#   How do I parse a string to an integer in Rust?

 In Rust, you can parse a string to an integer using the `parse` method, which is available on string slices (`&str`). The `parse` method returns a `Result`, which you should handle properly, especially since it can fail if the string does not represent a valid integer.

Here's a step-by-step guide on how to parse a string to an integer in Rust:

1. **Define a string slice**: This is the string you want to parse.
2. **Call the `parse` method**: This method attempts to parse the string into the specified type.
3. **Handle the `Result`**: Since `parse` returns a `Result`, you need to handle both the successful case (where the parse is successful) and the error case (where the parse fails).

Here's an example:

```rust
fn main() {
    let string_number = "42";
    
    // Attempt to parse the string into an integer
    match string_number.parse::<i32>() {
        Ok(number) => println!("Parsed integer: {}", number),
        Err(e) => println!("Failed to parse: {}", e),
    }
}
```

In this example:
- `string_number` is a string slice that holds the number "42".
- `string_number.parse::<i32>()` attempts to parse the string as an `i32`.
- The `match` statement is used to handle the `Result`. If parsing is successful, `Ok(number)` is returned, and you can use `number` as an integer. If parsing fails, `Err(e)` is returned, and you can handle the error.

### Example with Error Handling

Here's a more comprehensive example that includes error handling:

```rust
fn main() {
    let string_number = "42";
    
    // Attempt to parse the string into an integer
    let number: Result<i32, _> = string_number.parse();
    
    match number {
        Ok(n) => println!("Parsed integer: {}", n),
        Err(e) => println!("Failed to parse: {}", e),
    }
}
```

In this example:
- `let number: Result<i32, _> = string_number.parse();` directly assigns the result of the parse operation to `number`.
- The `match` statement is used to handle the `Result`. If parsing is successful, `Ok(n)` is returned, and you can use `n` as an integer. If parsing fails, `Err(e)` is returned, and you can handle the error.

### Using `expect` for Panic on Error

If you prefer to panic on error and want a more concise way to handle it, you can use the `expect` method:

```rust
fn main() {
    let string_number = "42";
    
    // Attempt to parse the string into an integer and panic on error
    let number = string_number.parse::<i32>().expect("Failed to parse string to integer");
    
    println!("Parsed integer: {}", number);
}
```

In this example:
- `string_number.parse::<i32>().expect("Failed to parse string to integer")` attempts to parse the string and panics with the provided message if the parse fails.

Choose the method that best fits your needs based on how you want to handle errors.
