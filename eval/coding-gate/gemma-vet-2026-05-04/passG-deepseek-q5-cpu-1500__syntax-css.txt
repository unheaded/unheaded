#   How do I center a div?

 Centering a `div` can be done in several ways depending on whether you want to center it horizontally, vertically, or both. Here are some common methods:

### 1. Centering Horizontally

#### Using `margin: auto`
If the `div` has a fixed width and is inside a container with a known width, you can use `margin: auto`:

```html
<div class="container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.container {
  width: 80%;
  border: 1px solid #000;
  text-align: center; /* Optional: Centers text inside the div */
}

.centered {
  width: 50%;
  margin: 0 auto;
  border: 1px solid red;
}
```

#### Using Flexbox
Flexbox is a more modern and flexible way to center elements:

```html
<div class="flex-container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.flex-container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh; /* Optional: Centers vertically within the viewport */
}

.centered {
  border: 1px solid red;
}
```

### 2. Centering Vertically

#### Using Flexbox
Flexbox is also very effective for vertical centering:

```html
<div class="flex-container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.flex-container {
  display: flex;
  align-items: center;
  height: 100vh; /* Optional: Centers horizontally within the viewport */
}

.centered {
  margin: auto;
  border: 1px solid red;
}
```

#### Using Grid Layout
CSS Grid is another modern way to center elements:

```html
<div class="grid-container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.grid-container {
  display: grid;
  place-items: center;
  height: 100vh; /* Optional: Centers both horizontally and vertically */
}

.centered {
  border: 1px solid red;
}
```

### 3. Centering Both Horizontally and Vertically

#### Using Flexbox
Combine `justify-content: center` and `align-items: center`:

```html
<div class="flex-container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.flex-container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

.centered {
  border: 1px solid red;
}
```

#### Using Grid Layout
Use `place-items: center` in the grid container:

```html
<div class="grid-container">
  <div class="centered">Centered Div</div>
</div>
```

```css
.grid-container {
  display: grid;
  place-items: center;
  height: 100vh;
}

.centered {
  border: 1px solid red;
}
```

Choose the method that best fits your layout and requirements. Flexbox and Grid are highly recommended for modern web design due to their flexibility and ease of use.
