#   How do I center a div?

To center a `div` element both horizontally and vertically, you can use several methods depending on your layout needs and the version of CSS you are using. Here are a few common approaches:

### 1. Flexbox (Modern and Recommended)
Flexbox is a powerful layout module that makes centering elements straightforward.

```html
<div class="container">
  <div class="centered-div">
    Centered Content
  </div>
</div>
```

```css
.container {
  display: flex;
  justify-content: center; /* Centers horizontally */
  align-items: center;    /* Centers vertically */
  height: 100vh;          /* Full viewport height */
}

.centered-div {
  /* Additional styles for your centered div */
}
```

### 2. Grid (Modern)
CSS Grid is another modern layout module that can be used for centering.

```html
<div class="container">
  <div class="centered-div">
    Centered Content
  </div>
</div>
```

```css
.container {
  display: grid;
  place-items: center;    /* Centers both horizontally and vertically */
  height: 100vh;          /* Full viewport height */
}

.centered-div {
  /* Additional styles for your centered div */
}
```

### 3. Absolute Positioning with Transform
This method is useful when you want to center a `div` relative to its parent.

```html
<div class="container">
  <div class="centered-div">
    Centered Content
  </div>
</div>
```

```css
.container {
  position: relative;
  height: 100vh;          /* Full viewport height */
}

.centered-div {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 4. Margin Auto (Horizontal Centering)
This method centers a `div` horizontally but not vertically.

```html
<div class="container">
  <div class="centered-div">
    Centered Content
  </div>
</div>
```

```css
.container {
  text-align: center;      /* Centers inline elements */
}

.centered-div {
  display: inline-block;  /* Makes the div inline for centering */
  margin: 0 auto;          /* Centers horizontally */
}
```

### 5. Table Display (Legacy)
This method uses the `display: table` and `display: table-cell` properties to center content.

```html
<div class="container">
  <div class="centered-div">
    Centered Content
  </div>
</div>
```

```css
.container {
  display: table;
  height: 100vh;          /* Full viewport height */
  width: 100%;
}

.centered-div {
  display: table-cell;
  text-align: center;      /* Centers horizontally */
  vertical-align: middle;  /* Centers vertically */
}
```

Choose the method that best fits your project's requirements and the browsers you need to support. Flexbox and Grid are generally the most flexible and modern solutions.
