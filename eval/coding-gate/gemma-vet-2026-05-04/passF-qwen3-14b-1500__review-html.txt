### ✅ **1. Missing `alt` Attribute on the `<img>` Tag**

**Issue:**  
The `<img>` tag is missing the `alt` attribute, which is required for accessibility. The `alt` attribute provides a textual description of the image, which is crucial for screen readers and users who cannot see the image.

**Fix:**  
Add an appropriate `alt` attribute to the `<img>` tag. For example:

```html
<img src="/static/logo.svg" alt="Dashboard Logo" width="120">
```

This tells assistive technologies that the image is a logo for the dashboard.

---

### ✅ **2. Using the `width` Attribute on `<img>` is Not Recommended**

**Issue:**  
While using the `width` attribute on the `<img>` tag is not invalid, it is considered outdated and less flexible. It can cause layout issues on responsive designs and is harder to maintain.

**Fix:**  
Use CSS to define the width instead
