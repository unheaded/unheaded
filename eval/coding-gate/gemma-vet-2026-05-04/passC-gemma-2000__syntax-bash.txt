Since Bash itself doesn't have a single built-in function specifically named `trim`, you typically achieve this using a combination of **Bash Parameter Expansion**, **`sed`**, or **`awk`**.

The best method depends on whether you need a quick one-liner, a robust function, or maximum portability.

Here are the three most effective ways to trim whitespace in Bash.

---

## Method 1: Using Bash Parameter Expansion (The Pure Bash Way)

For simple trimming of leading and trailing spaces, Bash's built-in parameter expansion is the fastest and most efficient method, as it doesn't require spawning external processes.

### 1. Trim Leading Whitespace

Use the `${variable##pattern}` syntax to remove the longest matching prefix.

```bash
input="   Hello World"
trimmed_start="${input#"${input%%[![:space:]]*}"}"
echo "$trimmed_start"
# Output: Hello World
```

### 2. Trim Trailing Whitespace

Use the `${variable%%pattern}` syntax to remove the longest matching suffix.

```bash
input="Hello World   "
trimmed_end="${input%"${input##*[![:space:]]}"}"
echo "$trimmed_end"
# Output: Hello World
```

### 3. Trim Both Leading and Trailing Whitespace (The Combined Approach)

To trim both sides, you combine the two techniques.

```bash
input="   Data to trim   "

# Step 1: Trim leading whitespace
trimmed_start="${input#"${input%%[![:space:]]*}"}"

# Step 2: Trim trailing whitespace from the result of Step 1
final_trimmed="${trimmed_start%"${trimmed_start##*[![:space:]]}"}"

echo "$final_trimmed"
# Output: Data to trim
```

> **💡 Note on Bash Parameter Expansion:** This method is fast, but the syntax is complex and can be difficult to read for beginners.

---

## Method 2: Using `sed` (The Robust and Standard Way)

If you need a solution that is highly readable and handles various types of whitespace (spaces, tabs, newlines) using regular expressions, `sed` is the ideal tool.

### The `sed` Command

This command uses regular expressions to remove one or more whitespace characters (`[[:space:]]`) from the beginning (`^`) and the end (`$`) of the line.

```bash
input="   Data with tabs\t   "

# The command:
# 1. s/^[[:space:]]*//  -> Substitute (s) any leading whitespace (^) with nothing
# 2. s/[[:space:]]*$//  -> Substitute (s) any trailing whitespace ($) with nothing
trimmed=$(echo "$input" | sed -e 's/^[[:space:]]*//' -e 's/[[:space:]]*$//')

echo "$trimmed"
# Output: Data with tabs
```

> **✅ Pros:** Highly robust, handles all types of whitespace (spaces, tabs, newlines), and is very readable once you understand the regex.
> **❌ Cons:** Requires spawning an external process (`sed`), making it slightly slower than pure Bash built-ins for extremely simple tasks.

---

## Method 3: Creating a Reusable Bash Function (The Best Practice)

If you plan to use this trimming logic repeatedly in your scripts, the best approach is to define a reusable function. This makes your code clean and easy to maintain.

```bash
# Define the trim function
trim() {
    local var="$1"
    # Use sed for robust trimming
    echo "$var" | sed -e 's/^[[:space:]]*//' -e 's/[[:space:]]*$//'
}

# --- Example Usage ---

data1="   This is a test.   "
data2="\tAnother test with tabs\n"

echo "Original 1: '$data1'"
echo "Trimmed 1:  '$((trim "$data1"))'"
echo "------------------------"
echo "Original 2: '$data2'"
echo "Trimmed 2:  '$((trim "$data2"))'"
```
