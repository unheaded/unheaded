#   What's the right tag for a clickable button?

The correct tag for a **clickable button** in HTML is the `<button>` tag. It is the **semantically appropriate** and **most flexible** choice for creating buttons that perform actions (e.g., submitting forms, triggering JavaScript, etc.).

### ✅ Recommended Usage: `<button>`
```html
<button type="button">Click Me</button>
```

### Key Advantages of `<button>`:
1. **Semantics**: Clearly indicates a button to both users and developers.
2. **Flexibility**: Can contain text, icons, or other HTML elements (e.g., `<img>`, `<span>`, `<div>`).
3. **Accessibility**: Works well with screen readers and keyboard navigation when used properly.
4. **Styling**: Easily styled with CSS (e.g., `background-color`, `padding`, etc.).

---

### 🔄 Alternatives (Less Ideal for Buttons):
1. **`<input type="button">`**  
   - For simple buttons without nested content.  
   - Less flexible than `<button>`.  
   ```html
   <input type="button" value="Submit">
   ```

2. **`<a href="#">`**  
   - Use only if the button is a **link** (e.g., navigating to another page).  
   - Not ideal for form actions or non-navigational purposes.  
   ```html
   <a href="#">Click Me</a>
   ```

---

### 📌 Best Practice:
- Use `<button>` for **interactive actions** (e.g., form submission, toggling content).
- Use `<a>` for **navigation** (e.g., linking to another page or section).
- Avoid using `<div>` or `<span>` with `onclick` unless absolutely necessary (not semantically correct).

Example with form submission:
```html
<form>
  <button type="submit">Submit Form</button>
</form>
```
