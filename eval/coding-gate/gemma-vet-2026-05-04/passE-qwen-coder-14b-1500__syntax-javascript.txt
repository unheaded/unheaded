#   How do I make an async fetch call?

To make an asynchronous fetch call in JavaScript, you can use the `fetch` function, which is built into modern browsers. The `fetch` function returns a promise that resolves to the `Response` object representing the response to the request. Here's a basic example of how to use `fetch` to make an asynchronous GET request:

```javascript
async function fetchData(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error('Network response was not ok ' + response.statusText);
    }
    const data = await response.json(); // or response.text(), response.blob(), etc.
    console.log(data);
  } catch (error) {
    console.error('There was a problem with the fetch operation:', error);
  }
}

// Usage
fetchData('https://api.example.com/data');
```

### Explanation:

1. **`async` Function**: The `fetchData` function is declared as `async`, which allows the use of the `await` keyword inside it. This makes the function asynchronous.

2. **`await` Keyword**: The `await` keyword is used to pause the execution of the function until the promise returned by `fetch` is resolved. This allows you to write asynchronous code that looks synchronous.

3. **Error Handling**: The `try...catch` block is used to handle any errors that might occur during the fetch operation, such as network issues or invalid responses.

4. **Response Handling**: The `response.ok` property checks if the response status code is in the range 200-299. If not, an error is thrown. The `response.json()` method is used to parse the response body as JSON. You can also use `response.text()`, `response.blob()`, etc., depending on the expected response format.

### Additional Options:

You can also make POST requests or include additional options in the fetch call, such as headers or request body. Here's an example of a POST request:

```javascript
async function postData(url, data) {
  try {
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(data)
    });

    if (!response.ok) {
      throw new Error('Network response was not ok ' + response.statusText);
    }

    const result = await response.json();
    console.log(result);
  } catch (error) {
    console.error('There was a problem with the fetch operation:', error);
  }
}

// Usage
postData('https://api.example.com/data', { key: 'value' });
```

In this example, the `fetch` function is called with a second argument, an options object, which specifies the HTTP method, headers, and body of the request.
