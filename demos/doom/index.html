Key Bindings (Doom Internal Keycodes)

Movement
↑ / W = Forward (0xAD)
↓ / S = Back (0xAF)
← / A = Strafe Left (0xAC)
→ / D = Strafe Right (0xAE)
Actions
Ctrl = Fire (0xA3)
Space = Use (0xA2)
Shift = Run (0xB6)
Alt = Strafe (0xA4)
Weapons
1–9 = Weapon Select
0 = Deselect
Other
Tab = Map
Esc = Menu
Enter = Accept

This viewer sends keypresses to the Monad CPU's BPF KBD_MAP. Screen updates are received via WebSocket from the DOOM CPU emulator. Based on Doom internal keycode mapping (not IBM scan codes).
