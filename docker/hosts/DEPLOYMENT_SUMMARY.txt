QUICK START STEPS
================================================================================

HOST-A (FORGE) - Full Stack:

  1. Generate WireGuard Keys:
     $ wg genkey | tee host-a.private.key | wg pubkey > host-a.public.key

  2. Configure Environment:
     $ cd host-a
     $ cp .env.example .env
     $ nano .env
     (Enter WireGuard keys, Grafana password)

  3. Start Services:
     $ docker-compose up -d

  4. Verify Status:
     $ docker-compose ps
     $ docker-compose logs -f

  5. Access Services:
     Grafana: http://localhost:3001 (admin/password)
     Prometheus: http://localhost:9090
     NATS: localhost:4222
