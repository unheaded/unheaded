USAGE EXAMPLES
================================================================================

View documentation:
  $ cat README.md                # Full reference guide
  $ cat INDEX.md                 # Quick reference
  $ cat default.yaml             # Template reference

Launch a single service:
  $ lxc init ubuntu:24.04 unheaded-monad < monad.yaml
  $ lxc start unheaded-monad

List all services:
  $ lxc list | grep unheaded

Get service IP and port:
  $ lxc list unheaded-monad     # Shows IP
  # Access: <ip>:50051

View service logs:
  $ lxc file pull unheaded-monad/var/log/unheaded/monad.log -

Update service binary:
  $ go build -o /opt/unheaded/bin/monad ./cmd/monad
  $ lxc restart unheaded-monad

Check container configuration:
  $ lxc config show unheaded-monad
  $ lxc device list unheaded-monad

DEPLOYMENT WORKFLOW
================================================================================

1. Prepare Infrastructure:
   - Create LXD profiles (unheaded-base, unheaded-ebpf, unheaded-telemetry)
   - Create "unheaded" network bridge
   - Create "unheaded-ssd" storage pool
   - Create /var/lib/unheaded/* state directories
   - Create /var/log/unheaded shared log directory

2. Prepare Binaries:
   - Compile all services to /opt/unheaded/bin/<service>
   - Verify executable permissions

3. Deploy Containers:
   - Use ./launch.sh (launches all in priority order)
   - Or manually: lxc init ubuntu:24.04 unheaded-<name> < <name>.yaml
   - Services auto-start in priority order (Wotan first, Lich last)

4. Verify Operation:
   - Check: lxc list | grep unheaded
   - Check logs: lxc file pull unheaded-service/var/log/unheaded/* -
   - Test connectivity to each service port

5. Monitor:
   - Use Grafana dashboard (port 3000)
   - Check Prometheus metrics (port 9090)
   - Review logs in Loki (port 3100)
