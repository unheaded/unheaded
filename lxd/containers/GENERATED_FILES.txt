USAGE INSTRUCTIONS
================================================================================

Launch single service:
  $ lxc init ubuntu:24.04 unheaded-monad < containers/monad.yaml
  $ lxc start unheaded-monad

Launch via script:
  $ ./launch.sh monad

Verify configuration:
  $ lxc config show unheaded-monad
  $ lxc device list unheaded-monad

Check container status:
  $ lxc list | grep unheaded

Access service:
  $ lxc list unheaded-monad  # Get container IP
  # Connect to: <ip>:<port>

View logs:
  $ lxc file pull unheaded-monad/var/log/unheaded/monad.log -

Update binary:
  $ go build -o /opt/unheaded/bin/monad ./cmd/monad
  $ lxc restart unheaded-monad
