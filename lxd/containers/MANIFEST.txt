## Key Features

1. **Bind-Mount Pattern**: Binary (read-only) + State (read-write) + Logs (shared)
2. **Environment Variables**: Service configuration via env vars (SERVICE_PORT, WOTAN_ADDR, etc.)
3. **Resource Isolation**: CPU/memory limits per tier
4. **Profile-Based Config**: Shared settings via LXD profiles
5. **Persistent State**: Service state survives container restart
6. **Centralized Logging**: All containers log to /var/log/unheaded

## Usage

Launch individual service:
```bash
lxc init ubuntu:24.04 unheaded-monad < containers/monad.yaml
lxc start unheaded-monad
```

Or use launch.sh:
```bash
./launch.sh monad
```
